# Ελληνικοί Υπότιτλοι — τοπικό addon για το Stremio

Βρίσκει υπότιτλους για ό,τι βλέπεις στο Stremio και, όταν δεν υπάρχει **πραγματικός**
ελληνικός, μεταφράζει τον αγγλικό αυτόματα στα ελληνικά. Τρέχει μόνο στον υπολογιστή
σου (`127.0.0.1`) — τίποτα δεν εκτίθεται στο δίκτυο.

## Τι κάνει, με τη σειρά

1. **Ψάχνει πραγματικούς ελληνικούς** (SubDL). Αν βρει, τους σερβίρει όπως είναι —
   μηδέν κόστος, μηδέν μετάφραση.
2. Αν δεν βρει, **παίρνει τον αγγλικό** και τον μεταφράζει με το **Gemini (δωρεάν
   όριο)**· αν αυτό δεν απαντήσει, με το **τοπικό μοντέλο του LM Studio**.
3. Η μετάφραση γίνεται **μία φορά ανά επεισόδιο/ταινία** και μένει στον δίσκο
   (`.cache/`). Το επόμενο άνοιγμα του μενού υποτίτλων είναι ακαριαίο.
4. Ό,τι δεν μεταφραστεί (σπάνια, π.χ. μπλοκάρισμα «ασφάλειας») **μένει στα αγγλικά**
   αντί να χαθεί όλη η δουλειά.

## Εγκατάσταση

Χρειάζεται **Node 22+** (`node -v`).

```bash
npm install
cp .env.example .env      # και συμπλήρωσε τα δύο κλειδιά
npm run check             # τι βλέπει: πηγές, μηχανές, όριο, μνήμη
```

## Φορητό πακέτο για άλλον υπολογιστή

```bash
node tools/make-portable.mjs      # -> dist/Stremio-Greek-Subs-portable.zip
```

Μέσα στο zip: τα αρχεία του έργου, οι βιβλιοθήκες (`node_modules`) και το ίδιο το
Node — γι' αυτό ο παραλήπτης δεν εγκαθιστά τίποτα. Αποσυμπιέζει, τρέχει το
`Start-Addon.cmd`, βάζει **τα δικά του** κλειδιά (SubDL + Google) στο `.env` που του
ανοίγει μόνο του, και δουλεύει. Οι οδηγίες που βλέπει είναι το `tools/ODIGIES.txt`.

Έξω από το πακέτο μένουν πάντα: `.env` (τα κλειδιά), `cache/`, `output/`, `dist/`,
`.git/`. Αν αλλάξεις αυτή τη λίστα, άλλαξες και το ποιος βλέπει τα κλειδιά σου.

## Ξεκίνημα — τι πατάς κάθε φορά

Ο server είναι ένα μικρό πρόγραμμα που τρέχει στον υπολογιστή σου και απαντά στο
Stremio. Δεν είναι υπηρεσία στο internet: όσο τρέχει, οι υπότιτλοι υπάρχουν· αν
κλείσει, το Stremio δεν βλέπει το addon.

| Τρόπος | Τι κάνει |
|---|---|
| **«Ελληνικοί Υπότιτλοι»** στην Επιφάνεια Εργασίας | Διπλό κλικ: αν ο server δεν τρέχει, τον ξεκινά· αν τρέχει, απλώς ανοίγει τη σελίδα. Αυτό είναι το καθημερινό. |
| `Start-Addon.cmd` (στον φάκελο του έργου) | Το ίδιο με το πιο πάνω — η συντόμευση δείχνει εδώ. |
| Αυτόματη Εκκίνηση | Υπάρχει συντόμευση στο `Startup` των Windows (`…\Start Menu\Programs\Startup`): ο server ξεκινά μόνος του με τα Windows, ελαχιστοποιημένος. **Για να το απενεργοποιήσεις, σβήσε αυτή τη συντόμευση.** |
| `npm start` | Χειροκίνητα, από τερματικό (δείχνει και το log ζωντανά). |

Το παράθυρο του server **μένει ανοιχτό** — αυτό είναι ο server. Σταματά με `Ctrl+C`
ή κλείνοντας το παράθυρο. Τίποτα δεν χαλάει αν τον ξεκινήσεις δύο φορές: η δεύτερη
διεργασία βλέπει ότι τρέχει ήδη και αποσύρεται.

Οι συντομεύσεις ξαναφτιάχνονται (π.χ. αν μετακινήσεις τον φάκελο) με:

```bash
powershell -ExecutionPolicy Bypass -File tools\make-shortcuts.ps1
```

**Διεύθυνση:** `127.0.0.1` σημαίνει «αυτός εδώ ο υπολογιστής» (localhost) — γι' αυτό
δουλεύει χωρίς δίκτυο και δεν το βλέπει κανείς άλλος. Το `7000` είναι η «πόρτα»
στην οποία ακούει· αλλάζει από το `PORT` στο `.env`.

Δύο κλειδιά, και τα δύο **δωρεάν**:

| Κλειδί | Από πού | Όριο δωρεάν |
|---|---|---|
| `SUBDL_API_KEY` | subdl.com → Panel → API | 2000 αναζητήσεις + 50 λήψεις/ημέρα |
| `GEMINI_API_KEY` | aistudio.google.com/apikey | επαρκές για μετάφραση (δεν θέλει κάρτα) |

Το `GEMINI_MODEL` μένει **κενό**: το addon διαλέγει μοντέλο μόνο του, δοκιμάζοντάς το
με πραγματικό αίτημα (η Google αποσύρει μοντέλα και βάζει άλλα σε αναμονή φόρτου).

## Στο Stremio

Με τον διακομιστή να τρέχει, άνοιξε:

```
http://127.0.0.1:7000/
```

και πάτησε το κουμπί εγκατάστασης — ή βάλε χειροκίνητα
`http://127.0.0.1:7000/manifest.json` στα Addons.

Μετά, όταν βάζεις ταινία/επεισόδιο: **υπότιτλοι → «Ελληνικοί»**. Αν δεις
«μετάφραση σε εξέλιξη», ξανάνοιξε το μενού σε λίγο: με ~70 cues το αίτημα, ένα
επεισόδιο θέλει περίπου ένα λεπτό.

## Σελίδες

| Διεύθυνση | Τι δείχνει |
|---|---|
| `/` | αρχική με το κουμπί εγκατάστασης και τη λίστα «Έτοιμοι για upload» |
| `/admin` | όριο πηγής, ουρά μεταφράσεων, τι είναι στη μνήμη, log, φάκελος output |
| `/output/<όνομα>` | κατέβασμα ενός έτοιμου υπότιτλου |
| `/manifest.json` | το manifest για το Stremio |

## Ο φάκελος `output/` — έτοιμοι για upload

Κάθε υπότιτλος που παράγεται (μετάφραση) ή κατεβαίνει (πραγματικός ελληνικός)
αντιγράφεται και σε αρχείο έτοιμο για ανέβασμα, με όνομα που ταιριάζει με το βίντεο:

```
output/Teenage.Sex.And.Death.At.Camp.Miasma.2026.1080p.WEBRip.x264.AAC-[YTS.GG - YTS.BZ]-Greek.srt
```

Ο φάκελος είναι `D:\Hermes Agent\Projects\stremio-greek-subs\output` (αλλάζει με το
`OUTPUT_DIR` στο `.env`). Δίπλα στο όνομα του βίντεο μπαίνει μόνο το `-Greek` — ό,τι
ζητάνε τα sites υποτίτλων — και τίποτα άλλο δεν πειράζεται: τελείες, αγκύλες, όνομα
ομάδας μένουν όπως τα κατέβασες.

- **Ίδιο έργο, άλλο release** → δεύτερο αρχείο με το νέο όνομα, χωρίς νέα μετάφραση.
- **Ξανάνοιγμα του μενού υποτίτλων** → το αρχείο δεν ξαναγράφεται, οπότε δεν αλλάζει
  ημερομηνία σε κάτι που έχεις ήδη ανεβάσει.
- **Λήψη** → από τη σελίδα `http://127.0.0.1:7000/` (ενότητα «Έτοιμοι για upload») ή
  απευθείας από `/output/<όνομα>`.
- **Χωρίς όνομα αρχείου** (π.χ. streaming χωρίς τοπικό αρχείο) → μπαίνει το όνομα του
  release, αλλιώς `tt0903747-S05E14-Greek.srt` από το imdb id και το επεισόδιο.

Δύο σημειώσεις: το `output/` **δεν** είναι cache — δεν σβήνεται μαζί της και κρατάει
ό,τι έχεις φτιάξει· και για υποτίτλους που βρέθηκαν έτοιμοι (όχι μεταφρασμένοι) το
περιεχόμενο δεν είναι δικό μας, οπότε το ανέβασμα είναι δική σου απόφαση.

## Έλεγχοι

```bash
npm test                      # 185 δοκιμές, χωρίς δίκτυο
LIVE=1 npm test               # + πραγματικό όριο, μετάφραση, αναζήτηση
LIVE=1 LIVE_E2E=1 npm test    # + ολόκληρες ροές (κατεβάζει και μεταφράζει)
node scripts/probe-models.mjs # ποιο μοντέλο Gemini απαντά τώρα
node scripts/probe-http.mjs   # έλεγχος του ζωντανού addon
```

Οι δοκιμές με `LIVE` καίνε όριο της πηγής (50 λήψεις/ημέρα) — γι' αυτό είναι
ξεχωριστές και δεν τρέχουν από μόνες τους.

## Φάση 2 (όχι ακόμη)

Κινητό/tablet στο ίδιο WiFi. Το Stremio δέχεται addon μόνο από `localhost` ή HTTPS,
άρα χρειάζεται `BIND_HOST=0.0.0.0` + διεύθυνση ή tunnel.
