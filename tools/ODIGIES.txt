ΕΛΛΗΝΙΚΟΙ ΥΠΟΤΙΤΛΟΙ ΓΙΑ ΤΟ STREMIO — φορητή έκδοση
===================================================

Τι είναι
  Ένα μικρό πρόγραμμα που τρέχει στον ΔΙΚΟ ΣΟΥ υπολογιστή και δίνει ελληνικούς
  υπότιτλους στο Stremio: πρώτα ψάχνει έτοιμους ελληνικούς, αλλιώς μεταφράζει
  αγγλικούς (δωρεάν) και τους κρατά σε μνήμη, ώστε την επόμενη φορά να είναι
  ακαριαίοι. Τίποτα δεν ανεβαίνει σε ξένο server: όλα γίνονται τοπικά, στον
  υπολογιστή σου. Μέσα στο πακέτο υπάρχει το Node και οι βιβλιοθήκες που
  χρειάζεται, οπότε δεν χρειάζεται καμία εγκατάσταση.

ΒΗΜΑ 1 — Αποσυμπίεση
  Δεξί κλικ στο .zip  ->  Extract All...  ->  Extract
  Άνοιξε τον φάκελο που θα βγει (Stremio-Greek-Subs). ΜΗΝ τρέξεις το Start-Addon.cmd
  μέσα από το zip — δεν δουλεύει, θέλει πρώτα αποσυμπίεση.
  Αν τα Windows λένε «το αρχείο ήρθε από άλλον υπολογιστή»: δεξί κλικ στο .zip ->
  Properties -> Unblock -> OK, και μετά αποσυμπίεση.

ΒΗΜΑ 2 — Τα δύο δωρεάν κλειδιά σου (2 λεπτά)
  Κλειδί 1, για να βρίσκει έτοιμους ελληνικούς υπότιτλους:
      https://subdl.com    ->  δωρεάν λογαριασμός  ->  Panel  ->  API
      (δωρεάν: 2000 αναζητήσεις + 50 λήψεις την ημέρα)
  Κλειδί 2, για τη μετάφραση όταν δεν υπάρχει έτοιμος:
      https://aistudio.google.com/apikey    ->  Create API key
      (δωρεάν, με τον λογαριασμό Google σου — δεν ζητάει κάρτα)
  Τα κλειδιά μένουν τοπικά σε ένα αρχείο στον υπολογιστή σου. Δεν τα στέλνεις πουθενά.

ΒΗΜΑ 3 — Πρώτη εκκίνηση
  Διπλό κλικ στο  Start-Addon.cmd
  Την πρώτη φορά ανοίγει το Σημειωματάριο με το αρχείο .env: γράψε τα δύο κλειδιά σου
  μετά τα  SUBDL_API_KEY=  και  GEMINI_API_KEY= , αποθήκευσε με Ctrl+S και κλείσε το
  Σημειωματάριο. Τρέξε πάλι το Start-Addon.cmd — θα ανοίξει η σελίδα του addon.

ΒΗΜΑ 4 — Στο Stremio
  Stremio  ->  Addons  ->  Install from URL  ->  βάλε:
      http://127.0.0.1:7000/manifest.json
  Μετά: παίζεις ταινία ή σειρά -> μενού υποτίτλων -> «Ελληνικοί».
  Την πρώτη φορά μπορεί να πάρει λίγα λεπτά (κατεβάζει και μεταφράζει). Μετά, ακαριαία.

Ο φάκελος output — για όποιον ανεβάζει υποτίτλους
  Κάθε υπότιτλος που φτιάχνεται σώζεται και στον φάκελο:
      output\ΟΝΟΜΑ-ΤΑΙΝΙΑΣ-ΟΠΩΣ-ΤΟ-ΒΙΝΤΕΟ-Greek.srt
  δηλαδή με όνομα ίδιο με το αρχείο του βίντεο, έτοιμο για ανέβασμα σε sites υποτίτλων.
  Τα κατεβάζεις και με ένα κλικ από τη σελίδα (ενότητα «Έτοιμοι για upload»).

Επόμενες φορές
  Διπλό κλικ στο Start-Addon.cmd. Αν τρέχει ήδη, απλώς ανοίγει τη σελίδα — δεν
  πειράζει τίποτα. Για συντόμευση στην Επιφάνεια Εργασίας: τρέξε το Make-Shortcut.cmd
  (προαιρετικά με -Startup, για να ξεκινά μόνο του με τα Windows).

Αν κάτι δεν δουλέψει
  - «Δεν βρήκα το Node.js» -> κατέβασε την έκδοση LTS από https://nodejs.org
  - Δεν βγαίνουν υπότιτλοι: άνοιξε τη σελίδα http://127.0.0.1:7000 (δείχνει ουρά
    μεταφράσεων, όριο πηγής και λάθη) και δες το αρχείο cache\addon.log
  - Λάθος ελληνικοί (άλλο release): βάλε SUBDL_MIN_MATCH_SCORE=0.9 στο .env
  - Ίντερνετ χρειάζεται μόνο για αναζήτηση και μετάφραση· ό,τι έχει μεταφραστεί
    μένει αποθηκευμένο στο cache, οπότε ξαναπαίζει χωρίς σύνδεση.
  - Ο υπολογιστής πρέπει να είναι ανοιχτός όσο βλέπεις — το πρόγραμμα τρέχει τοπικά.

Προαιρετικά: μετάφραση χωρίς ίντερνετ με τοπικό μοντέλο (LM Studio στο
http://127.0.0.1:1234) — συμπλήρωσε το LMSTUDIO_MODEL στο .env.
