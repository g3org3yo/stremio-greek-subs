# Ελληνικοί Υπότιτλοι — τοπικό addon για το Stremio

Βρίσκει υπότιτλους για ό,τι βλέπεις στο Stremio και, όταν δεν υπάρχει **πραγματικός**
ελληνικός, μεταφράζει τον αγγλικό αυτόματα στα ελληνικά. Τρέχει μόνο στον υπολογιστή
σου (`127.0.0.1`) — τίποτα δεν εκτίθεται στο δίκτυο.

## Τι κάνει, με τη σειρά

1. **Ψάχνει πραγματικούς ελληνικούς** (SubDL). Αν βρει, τους σερβίρει όπως είναι —
   μηδέν κόστος, μηδέν μετάφραση.
2. Αν δεν βρει, **παίρνει τον αγγλικό** και τον μεταφράζει με το **Gemini (δωρεάν
   όριο)**· αν αυτό δεν απαντήσει, με το **τοπικό μοντέλο του LM Studio**.
3. Η μετάφραση γίνεται **μία φορά ανά επεισόδιο/ταινία** και μένει στον δίσκο
   (`.cache/`). Το επόμενο άνοιγμα του μενού υποτίτλων είναι ακαριαίο.
4. Ό,τι δεν μεταφραστεί (σπάνια, π.χ. μπλοκάρισμα «ασφάλειας») **μένει στα αγγλικά**
   αντί να χαθεί όλη η δουλειά.

## Εγκατάσταση

Χρειάζεται **Node 22+** (`node -v`).

```bash
npm install
cp .env.example .env      # και συμπλήρωσε τα δύο κλειδιά
npm run check             # τι βλέπει: πηγές, μηχανές, όριο, μνήμη
npm start
```

Δύο κλειδιά, και τα δύο **δωρεάν**:

| Κλειδί | Από πού | Όριο δωρεάν |
|---|---|---|
| `SUBDL_API_KEY` | subdl.com → Panel → API | 2000 αναζητήσεις + 50 λήψεις/ημέρα |
| `GEMINI_API_KEY` | aistudio.google.com/apikey | επαρκές για μετάφραση (δεν θέλει κάρτα) |

Το `GEMINI_MODEL` μένει **κενό**: το addon διαλέγει μοντέλο μόνο του, δοκιμάζοντάς το
με πραγματικό αίτημα (η Google αποσύρει μοντέλα και βάζει άλλα σε αναμονή φόρτου).

## Στο Stremio

Με τον διακομιστή να τρέχει, άνοιξε:

```
http://127.0.0.1:7000/
```

και πάτησε το κουμπί εγκατάστασης — ή βάλε χειροκίνητα
`http://127.0.0.1:7000/manifest.json` στα Addons.

Μετά, όταν βάζεις ταινία/επεισόδιο: **υπότιτλοι → «Ελληνικοί»**. Αν δεις
«μετάφραση σε εξέλιξη», ξανάνοιξε το μενού σε λίγο: με ~70 cues το αίτημα, ένα
επεισόδιο θέλει περίπου ένα λεπτό.

## Σελίδες

| Διεύθυνση | Τι δείχνει |
|---|---|
| `/` | αρχική με το κουμπί εγκατάστασης |
| `/admin` | όριο πηγής, ουρά μεταφράσεων, τι είναι στη μνήμη, log |
| `/manifest.json` | το manifest για το Stremio |

## Έλεγχοι

```bash
npm test                      # 154 δοκιμές, χωρίς δίκτυο
LIVE=1 npm test               # + πραγματικό όριο, μετάφραση, αναζήτηση
LIVE=1 LIVE_E2E=1 npm test    # + ολόκληρες ροές (κατεβάζει και μεταφράζει)
node scripts/probe-models.mjs # ποιο μοντέλο Gemini απαντά τώρα
node scripts/probe-http.mjs   # έλεγχος του ζωντανού addon
```

Οι δοκιμές με `LIVE` καίνε όριο της πηγής (50 λήψεις/ημέρα) — γι' αυτό είναι
ξεχωριστές και δεν τρέχουν από μόνες τους.

## Φάση 2 (όχι ακόμη)

Κινητό/tablet στο ίδιο WiFi. Το Stremio δέχεται addon μόνο από `localhost` ή HTTPS,
άρα χρειάζεται `BIND_HOST=0.0.0.0` + διεύθυνση ή tunnel.
